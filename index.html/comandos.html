Comandos SQL

Comandos básicos para trabajar con bases de datos.

Create database

Se utiliza para crear una nueva base de datos.

Ejemplo:

Create database Escuela;

Create table

Se utiliza para crear una nueva tabla dentro de una base de datos.

Ejemplo:

Create table Alumnos (
ID_Alumno int,
Nombre varchar(30)
);

Drop table

Se utiliza para eliminar una tabla.

Ejemplo:

Drop table Alumnos;
