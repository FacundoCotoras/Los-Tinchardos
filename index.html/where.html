Comandos Select Where

Where

El comando Where se utiliza para establecer condiciones y mostrar solamente los registros que cumplen con ellas.

¿Para que sirve?

Where permite buscar informacion especifica dentro de una tabla. Se puede utilizar con numeros, textos y diferentes condiciones.

Ejemplo:

Select * from Alumnos Where Edad > 18;

Condiciones con texto

Tambien podemos utilizar Where para buscar un texto determinado.

Ejemplo:

Select * from Alumnos Where Nombre = 'Juan';

Otros operadores

Algunos operadores que se pueden utilizar con Where son:

  • = igual
  • > mayor que
  • < menor que
  • >= mayor o igual
  • <= menor o igual
  • <> distinto

Ejemplo:

Select * from Alumnos Where Edad < 18;
