Inner Join

Inner Join se utiliza para relacionar informacion de dos o mas tablas que tienen un dato en comun.

¿Como se utiliza?

Se indica la primera tabla, luego se utiliza Inner Join para relacionarla con otra tabla. Con On se indica que columnas tienen que coincidir.

Ejemplo:

Select Alumnos.Nombre, Cursos.Nombre
From Alumnos
Inner Join Cursos
On Alumnos.ID_Curso = Cursos.ID_Curso;

¿Para que sirve On?

On indica la condicion que se utiliza para relacionar las dos tablas.

Ejemplo:

Inner Join Cursos
On Alumnos.ID_Curso = Cursos.ID_Curso;

Importante

Inner Join muestra solamente los registros que tienen una coincidencia entre las tablas relacionadas.
