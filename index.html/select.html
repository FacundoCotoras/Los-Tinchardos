Comandos Select Where

Select

El comando Select se utiliza para consultar y mostrar informacion que se encuentra guardada en una tabla de la base de datos.

Seleccionar todos los datos

Se puede utilizar el simbolo * para mostrar todas las columnas de una tabla.

Ejemplo:

Select * from Alumnos;

Seleccionar algunas columnas

Tambien podemos elegir solamente las columnas que queremos mostrar.

Ejemplo:

Select Nombre, Apellido from Alumnos;

Select con Where

Select tambien se puede utilizar junto con Where para mostrar solamente los datos que cumplan una condicion.

Ejemplo:

Select * from Alumnos Where Edad > 18;
