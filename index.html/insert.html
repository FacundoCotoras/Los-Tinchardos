Insert

El comando Insert se utiliza para agregar nuevos registros dentro de una tabla de la base de datos.

¿Como se utiliza?

Primero se indica la tabla y las columnas donde se quieren guardar los datos. Despues se escriben los valores.

Ejemplo:

Insert into Alumnos (Nombre, Apellido, Edad)
Values ("Agustin", "Barrionuevo", 17);

Agregar varios registros

Tambien se pueden agregar varios registros utilizando diferentes valores.

Ejemplo:

Insert into Alumnos (Nombre, Apellido, Edad)
Values ("Agustin", "Barrionuevo", 17),
("Santiago", "Fidani", 20);

Importante

Los valores de texto se escriben entre comillas, y los numeros se escriben sin comillas.
