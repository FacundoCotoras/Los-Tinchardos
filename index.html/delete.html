Comandos Select Where

Delete

El comando Delete se utiliza para eliminar registros que se encuentran dentro de una tabla.

¿Como se utiliza?

Se indica la tabla de la cual queremos eliminar un registro y se utiliza Where para indicar cual queremos eliminar.

Ejemplo:

Delete from Alumnos
Where Nombre = 'Juan';

Eliminar varios registros

Tambien se pueden eliminar varios registros utilizando una condicion que coincida con varios datos.

Ejemplo:

Delete from Alumnos
Where Edad < 18;

Importante

Hay que tener cuidado al utilizar Delete sin Where, porque se eliminarian todos los registros de la tabla.
